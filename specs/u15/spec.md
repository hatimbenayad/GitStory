# Spec: U15 — Operations: CI, Deploy, Docs & Self-History Demo

## 1. Purpose & Why
Completes the Operations phase (Section 3.3) and final success criteria (Section 10): automated CI quality gates, static deployment config, publish-ready CLI packaging, developer documentation, and a real visual demo of GitStory replaying its own repository history.

## 2. Deliverables
- `.github/workflows/ci.yml`: Runs `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` on push and PR to `main`.
- `.github/workflows/deploy.yml` + `vercel.json`: Static web app deployment (`ADR-004`).
- Publish-ready `apps/cli/package.json` (`bin: { gitstory: "./dist/cli.js" }`, `files`, metadata — without publishing to npm).
- `README.md`: <5-minute quickstart, CLI & Web usage, architecture overview, embedded demo GIF.
- `CONTRIBUTING.md`: AI-DLC + SDD workflow, coding standards, Conventional Commits, testing instructions.
- `docs/runbook.md`: How to run, build, debug, benchmark, and add a new visualization view.
- `docs/demo/gitstory-demo.gif` (and `docs/demo/history.json` or generated directly via our own CLI + exporter): Real animated documentary generated by running GitStory on this repository itself!
- Final spec-to-code audit and verified GitHub push.
